# Startup wizard

**Category:** Compiler  
**Status:** Draft  
**Last updated:** 2026-07-24  

## Purpose

Guide founders through classification and answers so the Startup Compiler can select compatible meta-modules and assemble a launch-ready startup package.

## Scope

- Step-by-step intake (positioning, product, MVP, model, pricing, etc.)
- Branching questions by startup type
- Progress, save/resume, and validation of required answers
- Handoff of structured answers to module selection and artifact generation

## Out of scope

- Pitch deck structure specifically — Pitch wizard
- Risk/verification report generation — Risk and verification reports
- Runtime execution of assembled workflows — Operations runtime

## Inputs

| Input | Description |
|---|---|
| Founder answers | Form/wizard responses |
| Classification hints | Market, model, stage |
| Prior package state | Resume / revise flow |

## Outputs

| Output | Description |
|---|---|
| Structured intake record | Normalized answers |
| Classification | Startup type for compatibility |
| Compiler job request | Select modules + generate artifacts |

## Compatibility

Primary entry to Compilation context. Must not deploy high-risk packages without verification / expert review when thresholds are exceeded.

## Verification

- Required fields block incomplete compile
- Resume restores prior answers
- Classification changes re-run compatibility checks

# Pitch wizard

**Category:** Compiler  
**Status:** Draft  
**Last updated:** 2026-07-24  

## Purpose

Guide founders through pitch structure and narrative so the compiler can produce a coherent pitch artifact aligned with the startup package (problem, solution, market, model, ask).

## Scope

- Pitch section prompts (problem, solution, market, traction, model, team, ask)
- Reuse of startup-wizard answers where available
- Template selection by stage / audience
- Exportable pitch structure / deck outline bindings

## Out of scope

- Full startup classification intake — Startup wizard
- Legal or financial advice content — Legal & trust / expert modules
- Live investor CRM — Customer operations

## Inputs

| Input | Description |
|---|---|
| Startup package / intake | From compiler or startup wizard |
| Audience / stage | Angel, seed, internal, etc. |
| Pitch template | Section set and tone |

## Outputs

| Output | Description |
|---|---|
| Pitch structure | Ordered sections and copy slots |
| Pitch artifact bindings | Deck/doc generation inputs |
| Consistency flags | Gaps vs business model / pricing |

## Compatibility

Pitch output must not contradict selected pricing, legal, or product modules. High financial-promotion risk may require expert review.

## Verification

- Required pitch sections present for chosen template
- Numbers/claims flagged when missing evidence fields
- Regeneration after intake change updates pitch bindings
